
# CloudOps - DevOps Automation Platform

## Project Overview

CloudOps is an end-to-end DevOps project designed to
automate application testing, containerization,
infrastructure provisioning, deployment and monitoring
using Microsoft Azure.

## Technologies

- Linux
- Git and GitHub
- Python
- Docker
- Terraform
- Microsoft Azure
- GitHub Actions
- Azure Monitor
